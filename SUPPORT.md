# Support

How to get help with the Mammoth Python SDK (`mammoth-io`), the command-line interface (`mammoth-cli`) and the MCP server (`mammoth-mcp-server`).

- **Documentation:** https://mammoth.io/docs
- **Questions about your account, data or a workspace:** email support@mammoth.io. Include your workspace id, never an API key, token or secret.
- **A bug in the SDK, CLI or MCP server:** open an issue using the [bug report template](https://github.com/EdgeMetric/mammothsdk/issues/new?template=bug_report.yml). Include the package and version (`pip show mammoth-io`, `mammoth --version`) and the exact command or call that failed.
- **A feature request:** open an issue using the [feature request template](https://github.com/EdgeMetric/mammothsdk/issues/new?template=feature_request.yml).
- **A security problem:** do not open a public issue. Follow [SECURITY.md](SECURITY.md).
