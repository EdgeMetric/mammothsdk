# Security policy

## Reporting a vulnerability

Please do not report security problems in a public issue, pull request or discussion.

Email **support@mammoth.io** with the subject "Security: mammothsdk" and include:

- the affected package and version (`mammoth-io`, `mammoth-cli` or `mammoth-mcp-server`),
- what you found and the steps to reproduce it,
- the impact you expect.

Never include live API keys, tokens or customer data in the report; redact them.

We acknowledge reports within 3 business days and keep you updated until the issue is fixed. Fixes ship in a new release of the affected package, and we credit reporters who want credit.

## Supported versions

Only the latest published release of each package receives security fixes.
